Double Dragon III NES Static Recomp
Version: 1.0.0
Platform: native 64-bit Windows
Executable: Launcher.exe
Frontend: native Win32 launcher; statically linked SDL3 video, audio and gamepad input
Audio: 44,100 Hz mono PCM through a statically linked SDL3 audio stream
ROM: Double Dragon III - The Sacred Stones (USA) .nes required externally and not included

Changes in 1.0.0:
- Initial portable Windows release with the game-specific Double Dragon III static core.
- Included 20,166 fixed physical-bank and program-counter instruction contexts with fail-closed dispatch and no runtime opcode decoder or emulator fallback.
- Added the Windows Launcher, Welcome, About, Settings, Controls and Audio Settings windows.
- Included F1-F8 shortcuts for the guide, snapshots, settings, controls, audio, Run and screenshots.
- Supported two keyboard layouts, two gamepad slots, controller hot-plug handling and Keyboard, Gamepad or combined input.
- Stored frontend preferences and bindings in one settings.ini file beside Launcher.exe.
- Made Rom the default ROM discovery and Browse folder, with a remembered external browse folder.
- Included native 256x240 video, nearest-neighbour presentation, fit-to-window and 1x-4x scaling, optional 4:3 correction, VSync and full-screen play.
- Included 44,100 Hz mono audio, immediate volume changes and SDL3 queue-depth and drift correction.
- Added ROM-bound and generated-core-bound snapshots with SHA-256 payload integrity checks.
- Saved the displayed framebuffer to collision-safe screenshot files.
- Included portable Rom, Snapshots and Screenshots folders with explanatory readme files.
- Statically linked SDL3 and the Microsoft C/C++ runtime; no installer, separate SDL DLL or Visual C++ redistributable is required.
- Included the SDL controller database and third-party notices.
- Set Launcher.exe file and product metadata to version 1.0.0.
- Included the production source and build configuration; the original game ROM is supplied separately.
- Core coverage reaches the Mission Four transition. Missions Four and Five and the endings are not yet confirmed complete.
- Audio uses an event-driven renderer and is not cycle-perfect.
- Wide Screen is not included in version 1.0.0.
